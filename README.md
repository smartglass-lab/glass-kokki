# グラス国旗 — Glass Kokki

Meta Ray-Ban Display 用の**国旗図鑑＆クイズ**。世界93か国の国旗を画像ファイルなしで Canvas に描画し、←→でめくる**ずかん**、国旗を見て国名を当てる**4択クイズ**、「インドネシアとモナコ」「チャドとルーマニア」のような**そっくり国旗**を見分けるクイズを、タップとD-padだけで遊べる。ベスト記録を保存。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-kokki.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / 静的サイト）

## 特徴

- **タップとD-padだけで遊べる** — ↑↓でメニュー、←→↑↓で選択肢、タップで決定。戻るジェスチャーは使わず、どの画面もタップで先へ進める
- **93か国の国旗をコードで描画** — 横じま・縦じま・北欧十字・三日月・星・ユニオンジャック・太極・ネパールの二重三角など約20種類の描画プリミティブの組み合わせで表現。画像ファイルは1枚も使わない
- **📖 ずかん** — ←→で1か国ずつ、↑↓で地域（アジア／ヨーロッパ／アフリカ／北米・中南米／オセアニア）をジャンプ。国名・英語名・首都つき
- **❓ 国旗クイズ（10問）** — 国旗を見て4つの国名から選ぶ。誤答の選択肢は「似ている国旗」「同じ地域」から優先して出すのでほどよく難しい
- **👀 そっくり国旗（10問）** — 国名を見て、似ている2つの国旗（インドネシア／モナコ、ノルウェー／アイスランド、オーストラリア／ニュージーランド、カタール／バーレーン など27組）から正しい方を選ぶ
- **ベスト記録** — クイズ／そっくりそれぞれのベストを localStorage に保存。タイトル画面に表示
- **加算式ディスプレイ向けの絵** — 純黒の背景は透明。国旗は暗いパネル枠の中に描き、白い国旗（日本など）も輪郭が分かる

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらび、タップで「📖 ずかん」／「❓ 国旗クイズ」／「👀 そっくり国旗」／「💡 あそびかた」 |
| ずかん | ←→＝前／次の国、↑↓＝地域をジャンプ、タップ＝メニューへ |
| 国旗クイズ | ←→↑↓＝4つの選択肢を移動、タップ＝回答。正解／不正解が表示されたらタップで次の問題 |
| そっくり国旗 | ←→＝左右の国旗をえらぶ、タップ＝回答。表示後タップで次の問題 |
| 結果 | ↑↓でえらび、タップで「🔄 もういちど」／「◀ メニューへ」 |
| あそびかた | タップで とじる |
| PC確認用 | Escape でタイトルへ戻る、クリックでボタンを直接操作（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?demo=1` を付けると出題の乱数が固定され、記録も保存されません（デモ録画用）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E5%9B%BD%E6%97%97&appUrl=https%3A%2F%2Fglass-kokki.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス国旗`、URL `https://glass-kokki.vercel.app` を入力。
